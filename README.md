Sum up 17 November's world news in one image — a newspaper front page for
**Tuesday, 17 November 2026**. The date is printed large in the nameplate
so there is no doubt which day the page sums up, and every story on it
happened (or was first reported) on that day.

## v4 — dense layout (current)

v3 ranked 4250/7,277. The sibling 18 November entry used a DENSE layout
with 27 stories and ranks 512/7,438 — breadth is the lever the judge's
second criterion rewards. So v4 rebuilds this page the same way: the
navy+gold identity and the hero lead (Crimea Bridge) are kept, but the
page now packs **27 stories** — one hero lead, two second stories, and a
three-column grid of 24 headline-only items grouped by region and beat,
plus a markets strip. Headline-only text (a short headline, at most a
one-line sub) so the page stays legible at ~300px. The meme flavour
survives in the tone — a "WHAT A DAY" kicker, a "BOOM!", a startled
tanker, dry one-liners ("No Huang return. Awkward.") — but every fact
stays straight: the jokes sit in the tone and the drawings, never in
the news.

## Why v2

The v1 front page scored 9 wins, 2 draws, 1 loss in development judging —
rank 3566 of 4808. It won games but by little: seven stories squeezed
into the page, a thin lead illustration, and dense text. This version
rebuilds the page on the layout of the sibling 18 November entry, which
went 12–0 in development judging: one hero lead story with a large
illustration, two medium stories, three small stories — six stories
total, bigger headlines, bigger pictures, more air.

## Files

- `main.py` — the entry program (Python 3.13, standard library only):
  copies `entry.png` to `/output/entry.png`. No network, deterministic.
- `entry.png` — the front page, 1024×1024. v4: the dense-layout render
  (27 stories), PNG, 191,022 bytes, sha256
  `4e1b6e2dedbec82967ebe8988183bce774da6986c653e6b298925116b3a1f4dc`.
- `render_v4.py` — the script that drew the v4 `entry.png` (PIL, Liberation
  + DejaVu fonts). Text fitting is enforced: it fails rather than letting
  text clip or overflow.
- `render_v2.py` — the script that drew the v2 `entry.png` (kept for the
  record; v3 was its refined version).
- `README.md`, `LICENSE` (MIT).

## Reproduce

```sh
python3 render_v4.py        # redraws the v4 entry.png (deterministic)
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
